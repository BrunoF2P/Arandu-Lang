# Error P001: Unexpected Token

This error occurs when the parser encounters a token that does not match the grammatical rules at that position.

## Incorrect Code Example

```arandu
func main() {
    x = 10 +
}
```

## Semantic Explanation

The parser matches tokens against the grammar rules using Pratt parsing for expressions. If a token appears out of order (such as a closing brace directly after an addition operator), parsing fails.

The message states the expected construct in plain language and then shows the unexpected source text. Punctuation uses its source spelling, identifiers and keywords keep their source text, and end of input is described as “the end of the file.” Parser-internal token names (such as `EQUAL` or `IDENT_TYPE(...)`) are never shown. For example, it may say **Expected an expression here, but found `}`.**

## How to Fix

Ensure your syntax matches the language grammar:

```arandu
func main() {
    x = 10 + 5
}
```
